# Java Lab Sheet 10 - MCA203P

## Course: Object Oriented Programming Using Java
## Topics: Object-Oriented Programming with Collections, Inheritance, Encapsulation, Custom Models

### Programs Index:
1. `Q01_ArrayListStudent.java`: Student management using ArrayList with Student class, constructor, display(), add, remove, and iteration.
2. `Q02_LinkedListInheritanceEmployee.java`: Inheritance between Person (base) and Employee (derived) stored in LinkedList<Employee> with add, display, and search by name.
3. `Q03_HashSetAvoidDuplicatesBook.java`: HashSet with custom Book class overriding equals() and hashCode() to avoid duplicates by ID.
4. `Q04_TreeSetComparableProduct.java`: TreeSet with Product class implementing Comparable<Product> sorting by price.
5. `Q05_HashMapStudentRollNumber.java`: HashMap storing student roll number (key) and Student objects (value) with add, remove, and display methods.
6. `Q06_ArrayListInheritanceShapeCircle.java`: ArrayList<Shape> storing Circle objects demonstrating polymorphic method invocation of area().
7. `Q07_VectorEncapsulationCustomer.java`: Customer class with private fields and getters/setters stored in Vector<Customer>.
8. `Q08_StackCustomTaskManagement.java`: Stack<Task> simulating task management with push, pop, and display.
9. `Q09_QueueLinkedListPatientFIFO.java`: Queue<Patient> implemented using LinkedList simulating FIFO patient service.
10. `Q10_MultiCollectionInheritanceDeptTeacher.java`: Base class Department, subclass Teacher, storing departments in ArrayList and teachers in HashMap<Department, List<Teacher>>.

### How to Compile & Run:
```bash
# Compile all files
javac *.java

# Run any question (e.g. Q10)
java Q10_MultiCollectionInheritanceDeptTeacher
```
