# Java Lab Sheet 09 - MCA203P

## Course: Object Oriented Programming Using Java
## Topics: Java Collections Framework (List, Set, Queue, Iterators, Comparator)

### Index of Solutions:
1. `Q01_ArrayListInteger.java`: Create an ArrayList of integers and print all elements.
2. `Q02_ArrayListSize.java`: Add elements to an ArrayList and display its size.
3. `Q03_ArrayListInsertIndex.java`: Insert an element at a specific index in an ArrayList.
4. `Q04_ArrayListRemove.java`: Remove an element from an ArrayList by index and by value.
5. `Q05_ArrayListUpdate.java`: Update an element in an ArrayList at a given index.
6. `Q06_ArrayListForEach.java`: Iterate through an ArrayList using a for-each loop.
7. `Q07_ArrayListIterator.java`: Iterate through an ArrayList using an Iterator.
8. `Q08_ArrayListSort.java`: Sort an ArrayList of integers in ascending order.
9. `Q09_ArrayListReverse.java`: Reverse an ArrayList of strings.
10. `Q10_LinkedListStrings.java`: Create a LinkedList of strings and print elements.
11. `Q11_LinkedListAddFirstLast.java`: Add elements at the beginning and end of a LinkedList.
12. `Q12_LinkedListRemoveFirstLast.java`: Remove the first and last elements from a LinkedList.
13. `Q13_LinkedListGetFirstLast.java`: Retrieve the first and last elements from a LinkedList.
14. `Q14_HashSetDuplicates.java`: Create a HashSet of integers and add duplicate elements; observe rejection.
15. `Q15_HashSetRemove.java`: Remove an element from a HashSet.
16. `Q16_HashSetIterator.java`: Iterate through a HashSet using Iterator.
17. `Q17_TreeSetSorted.java`: Create a TreeSet of integers, add elements in random order, print sorted set.
18. `Q18_TreeSetContains.java`: Check if a TreeSet contains a specific element.
19. `Q19_LinkedHashSetOrder.java`: Create a LinkedHashSet of strings and maintain insertion order.
20. `Q20_CompareSets.java`: Compare HashSet, LinkedHashSet, and TreeSet with sample data.
21. `Q21_PriorityQueueInteger.java`: Create a PriorityQueue of integers, add elements, and print.
22. `Q22_PriorityQueueRemoveOrder.java`: Remove elements from a PriorityQueue and observe priority order.
23. `Q23_PriorityQueuePeek.java`: Peek the first element of a PriorityQueue without removing it.
24. `Q24_QueueLinkedList.java`: Use a Queue interface reference to refer to a LinkedList.
25. `Q25_QueueOperations.java`: Demonstrate adding, removing, and peeking elements in a Queue.
26. `Q26_ArrayListCustomObjectIterator.java`: Create an ArrayList of custom objects (Student) and iterate using Iterator.
27. `Q27_SortCustomObjectComparator.java`: Sort an ArrayList of custom objects using Comparator.
28. `Q28_ListToSetDuplicates.java`: Convert a List to a Set and observe duplicate removal.
29. `Q29_SetToListIteration.java`: Convert a Set to a List and iterate through it.
30. `Q30_ClearCollections.java`: Demonstrate clearing all elements from a List, Set, and Queue.

### How to Compile & Run:
```bash
# Compile all files
javac *.java

# Run any question (e.g. Q08)
java Q08_ArrayListSort
```
